# 日本史读本

一个以**阅读**为核心的个人日本史数字读物。纯静态站点，无构建步骤，无后端依赖，所有阅读记录保存在本机浏览器。

- 主线：康拉德·托特曼《日本史》（第二版）的通史框架
- 制度与权力结构：升味准之辅《日本政治史》
- 战败与占领：约翰·W·道尔《拥抱战败》

**七篇 90 章正文已全部完稿，约 22 万字。**

## 三、本地预览与部署

章节按需以 `<script>` 懒加载，直接双击 `index.html`（file:// 协议）在部分浏览器会被拦截，建议起本地服务：

```bash
cd japan-history
python -m http.server 8000
# 打开 http://127.0.0.1:8000/index.html
```

部署到 GitHub Pages：整个目录推到仓库根目录即可（已含 `.nojekyll`）。没有构建步骤，也没有任何需要保密的密钥。

## 四、如何新增一章

### 1. 新建 `data/ch-91.js`

```js
/* 第九十一章 */
(function (JH) {
  "use strict";

  JH.add({
    id: "c91",
    num: 91,
    part: 7,
    title: "章节标题",
    sub: "一句话副标题，显示在标题下方。",
    people: ["吉田茂"],            // 与 people.js / people2.js 中的 name 一致，会生成关联入口
    events: ["五五年体制"],        // 与 events.js / events2.js 中的 name 一致
    related: ["c90"],             // 延伸阅读
    sources: "本章主要依据……（显示在正文末尾「本章依据」）",
    body: `
## 一、小节标题

正文段落，空行分段。段内换行会被自动拼接。

> 引文内容|《平家物语》

:::note 争点：小标题
注释框内的段落。
:::
`
  });
})(window.JH);
```

### 2. 在 `data/site.js` 里登记

在该篇的 `chapters` 数组里加 `ch(91, "章节标题", true)`。

### 3. 校验

```bash
node tools/check.js
```

会检查：文件是否存在、是否注册成功、正文是否过短（<1800 字报警）、是否有未解析的 `:::` / `##` / `[[`、`sources` 是否缺失、人物与事件引用的章节是否有效。

## 五、正文语法（`body` 字段）

| 写法 | 效果 |
|---|---|
| 空行分段 | `<p>`（自动首行缩进 2em） |
| `## 标题` | 二级标题（带红色短线） |
| `### 标题` | 三级标题 |
| `> 引文\|出处` | 引用块，`\|` 之后为出处（可选） |
| `- 项目` / `1. 项目` | 无序 / 有序列表 |
| `**粗体**` / `*强调*` | 粗体 / 强调（强调为暗红色） |
| `:::note 小标题 … :::` | 注释框（用于史料说明、学界争点） |
| `:::figure 图形名\|图注 :::` | 插入 `JH.addDiagram()` 注册过的 SVG |
| `[[p:人物名]]` | 手动指定人物链接（一般不用手写，阅读页会自动把首次出现的人物、事件变成链接） |

> ⚠️ 正文写在 JS 模板字符串里，**禁止使用 ASCII 直引号 `"`**，一律用「」。否则会截断字符串导致语法错误。

自动关联逻辑在 `core.js` 的 `JH.linkify()`：按名字长度优先匹配，每章最多 36 处，标题、引文出处、注释标签内不插入。

## 六、关于参考书与引用的说明（重要）

1. **没有逐页核对原著。** 写作时使用的是三本书的公开目录结构、通行学术结论与常见史料，没有把三部书全文逐字读入后转写。正文中的「依据托特曼《日本史》第十三章……」指的是**观点与框架的归属**，不是原文引用或页码对应。
2. **升味准之辅《日本政治史》中文版是扫描件，没有文字层**，无法全文检索。相关部分依据其研究框架（政治史分期、官僚制与政党制的分析路径）与日本政治史通说写作，具体表述可能与原著有出入。
3. **不复制受版权保护的原文。** 所有正文均为自行撰写；引文只使用《魏志倭人传》《宋书》《隋书》《旧唐书》《日本书纪》等公版史籍，并注明篇名。
4. **争议问题的处理**：邪马台国位置、三角缘神兽镜产地、改新之诏真伪、绳文社会复杂程度、明治维新的性质、天皇的战争责任等，均以「争点」形式并列主要观点，不代替读者下结论。
5. **涉华史实**：日本侵华战争的性质、规模与后果按史实完整呈现——南京大屠杀（南京审判认定三十万人以上）、细菌战与七三一部队、化学战、慰安妇、强制劳工、三光作战，并说明东京审判豁免天皇与七三一部队的交易（第 58、68 章）。不作淡化，也不以民族主义叙事替代史实辨析。

## 七、阅读功能一览

- 阅读位置自动记忆（滚动节流保存，下次进入自动回到原位并提示百分比）
- 章节收藏 / 取消收藏
- 全站全文检索（首次进入时懒加载全部章节，建立段落级索引）
- 字号（16—24px）、行距（1.6—2.3）、版心宽度（28—46em）三项可调，设置写入 localStorage
- 人物索引、事件索引（锚点直达并高亮）、历史地图、八篇专题
- 上一章 / 下一章、相关章节、相关人物与事件
- 手机端：底部工具条（目录 / 字号 / 收藏 / 顶部）+ 抽屉式目录，正文区独立滚动，不与导航争空间
- 打印样式（隐藏导航与工具，正文转 12pt 单栏）

存储键：`nihonshi:v1`（`progress` / `last` / `marks` / `settings` / `visited`）。清除浏览器数据会丢失阅读记录。

## 八、已知限制

- **图片**：正文没有插入历史照片与画像，只用自绘 SVG 示意图。若要插图，需在 `core.js` 的 `render()` 中扩展 `:::img 路径|图注` 分支，并使用可确认授权来源的素材（如 Wikimedia Commons 的公有领域文件），在图注中注明来源。
- **检索**为逐字匹配，不做分词与同义词扩展。90 章全文索引在首次检索时建立，约需 1—2 秒。
- **未做 PWA 离线缓存**（可后续在 `sw.js` 中缓存 `data/*.js` 与 `assets/*`）。
- **人物与事件索引是选择性的**，不是全书人名的完整清单：收录标准是「在叙述中承担角色」。正文中未收入索引的名字不会生成链接。
