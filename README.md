# 日本史读本

一个以**阅读**为核心的个人日本史数字读物。纯静态站点，无构建步骤，无后端依赖，所有阅读记录保存在本机浏览器。

- 主线：康拉德·托特曼《日本史》（第二版）的通史框架
- 制度与权力结构：升味准之辅《日本政治史》
- 战败与占领：约翰·W·道尔《拥抱战败》

## 三、本地预览

因为章节是按需以 `<script>` 懒加载的，直接双击 `index.html`（file:// 协议）在部分浏览器可能被拦截，建议起一个本地服务：

```bash
cd japan-history
python -m http.server 8000
# 打开 http://127.0.0.1:8000/index.html
```

部署到 GitHub Pages：把整个 `japan-history` 目录推到仓库（或推到 `docs/`），在 Settings → Pages 里选分支与目录即可。没有构建步骤，也没有任何需要保密的密钥。

## 四、如何新增一章

### 1. 新建 `data/ch-13.js`

```js
/* 第十三章 */
(function (JH) {
  "use strict";

  JH.add({
    id: "c13",
    num: 13,
    part: 2,
    title: "源平合战",
    sub: "一句话副标题，显示在标题下方。",
    people: ["源赖朝", "源义经"],          // 与 people.js 中的 name 一致，会生成关联入口
    events: ["源平合战"],                  // 与 events.js 中的 name 一致
    related: ["c12", "c14"],               // 延伸阅读（仅对已完成章节生成链接）
    sources: "本章主要依据……（显示在正文末尾「本章依据」）",
    body: `
## 一、小节标题

正文段落，空行分段。段内换行会被自动拼接。

## 二、小节标题

> 引文内容|《平家物语》
> 引文可以跨行

:::note 争点：小标题
注释框内的段落。
:::

:::figure map-archipelago|图注文字
:::
`
  });
})(window.JH);
```

### 2. 在 `data/site.js` 里放行

找到第二篇的 `ch(13, "源平合战", false)`，把 `false` 改成 `true`。

### 3. 校验

```bash
node tools/check.js
```

会检查：文件是否存在、是否注册成功、正文是否过短（<1800 字报警）、是否有未解析的 `:::` / `##` / `[[`、`sources` 是否缺失、人物与事件引用的章节是否有效。

## 五、正文语法（`body` 字段）

| 写法 | 效果 |
|---|---|
| 空行分段 | `<p>`（自动首行缩进 2em） |
| `## 标题` | 二级标题（带红色短线） |
| `### 标题` | 三级标题 |
| `> 引文\|出处` | 引用块，`\|` 之后为出处（可选） |
| `- 项目` / `1. 项目` | 无序 / 有序列表 |
| `**粗体**` / `*强调*` | 粗体 / 强调（强调为暗红色） |
| `:::note 小标题 … :::` | 注释框（用于史料说明、学界争点） |
| `:::figure 图形名\|图注 :::` | 插入 `JH.addDiagram("图形名", svg)` 注册过的 SVG |
| `[[p:人物名]]` | 手动指定人物链接（一般不用手写，阅读页会自动把首次出现的人物、事件变成链接） |

自动关联逻辑在 `core.js` 的 `JH.linkify()`：按名字长度优先匹配，每章最多 36 处，标题、引文出处、注释标签内不插入。

## 六、关于参考书与引用的说明（重要）

1. **没有逐页核对原著。** 本站写作时使用的是三本书的公开目录结构、通行学术结论与常见史料，但没有把三部书全文逐字读入后转写。因此正文中的「依据托特曼《日本史》第五章……」指的是**观点与框架的归属**，不是原文引用或页码对应。
2. **升味准之辅《日本政治史》中文版是扫描件，没有文字层**，无法全文检索。本书相关部分依据其研究框架（政治史分期、官僚制与政党制的分析路径）与日本政治史的通说写作，具体表述可能与原著有出入。
3. **不复制受版权保护的原文。** 所有正文均为自行撰写；引文只使用《魏志倭人传》《宋书》《隋书》《旧唐书》《日本书纪》等公版史籍，并注明篇名。
4. **争议问题的处理**：邪马台国位置、三角缘神兽镜产地、改新之诏的真伪、绳文社会的复杂程度等，均以「争点」框并列主要观点，不代替读者下结论。
5. **涉华史实**：日本侵华战争的性质、规模与后果按史实完整呈现（见「日本侵华战争」专题），不作淡化；同时区分「事实」「学界解释」与「日本国内的不同立场」。

如果要进一步提高与原著的贴合度，建议的下一步是：对托特曼《日本史》按章做读书笔记（该书 PDF 有完整目录层级，可定位到页），把每章的关键判断摘录进对应章节的 `sources` 与注释框。

## 七、阅读功能一览

- 阅读位置自动记忆（滚动节流保存，下次进入自动回到原位并提示百分比）
- 章节收藏 / 取消收藏
- 全站全文检索（首次进入时懒加载已完成章节，建立段落级索引）
- 字号（16—24px）、行距（1.6—2.3）、版心宽度（28—46em）三项可调，设置写入 localStorage
- 人物索引、事件索引（锚点直达并高亮）、历史地图、八篇专题
- 上一章 / 下一章、相关章节、相关人物与事件
- 手机端：底部工具条（目录 / 字号 / 收藏 / 顶部）+ 抽屉式目录，正文区独立滚动，不与导航争空间
- 打印样式（隐藏导航与工具，正文转 12pt 单栏）

存储键：`nihonshi:v1`（`progress` / `last` / `marks` / `settings` / `visited`）。清除浏览器数据会丢失阅读记录。

## 八、已知限制

- 图片：目前正文没有插入历史照片与画像，全部使用自绘 SVG 示意图（列岛与海流、二官八省、五畿七道、平安京条坊、都城迁移）。插入真实图片时请使用可确认授权来源的素材（如 Wikimedia Commons 的公有领域文件），并在图注中注明来源；`:::figure` 目前只接受已注册的 SVG，若要插入位图需在 `core.js` 的 `render()` 中扩展一个 `:::img 路径|图注` 分支。
- 检索为逐字匹配，不做分词与同义词扩展；章节数量增加后（如超过 40 章），建议改为预生成索引文件，避免首屏加载过多脚本。
- 未做 PWA 离线缓存（可后续在 `sw.js` 中缓存 `data/*.js` 与 `assets/*`）。
